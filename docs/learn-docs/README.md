# Learn docs: the thinking behind `skill-from-domain`

Four notes from the learning that produced the core skill, cleaned of employer and personal detail. Written for the human who builds skills, not for the agent at run time: the skill's own `references/writing.md` already carries what the agent needs.

| File | Read it for |
|---|---|
| `method-elicit-diff-encode.md` | The three moves, each with principle, actions and done-when; the one-line version to tell others |
| `map.md` | Skill anatomy, the five schools compared, where they agree and split, the 13-line checklist, skills as job descriptions for an agent team, hooks as the deterministic layer |
| `vocabulary.md` | One row per term used across the repo: method, skill file, loading, writing, testing, harness |
| `crash-course-anthropic-skills.md` | The Anthropic primary sources condensed, with a maturity ladder, failure modes and exercises |

Start with the method note, then the map's checklist. The crash course is for a second pass against the official docs.

Where these notes and `skills/skill-from-domain/references/writing.md` differ, `writing.md` is current: it was aligned with Anthropic's `skill-creator` on 2026-11-11, and `docs/implementations/` holds the record.
